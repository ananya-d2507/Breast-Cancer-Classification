# Breast-Cancer-Classification
In this assignment we compare four classification algorithms, and it helps to find best performing  and worst performing modelsg 
What I Did in This Project

Loaded the Breast Cancer dataset from Scikit-learn.

Explored the dataset and its features.

Checked the dataset for missing values.

Separated the data into features (X) and target (y).

Split the dataset into training and testing sets.

Applied feature scaling where required.

Implemented five classification algorithms:

Logistic Regression

Decision Tree Classifier

Random Forest Classifier

Support Vector Machine (SVM)

K-Nearest Neighbors (KNN)

Made predictions using each model.

Evaluated the models using:

Accuracy

Confusion Matrix

Compared the performance of all five algorithms and analyzed their results.


🎯 Objective

The main objective of this project is to understand how different supervised classification algorithms perform on the same dataset and to compare their results using appropriate evaluation metrics.
